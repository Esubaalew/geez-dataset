# geez-dataset

Classical Ge'ez (ግዕዝ) morphology data. The gold files are verb paradigms and noun/adjective rows from *Merho Ges Wesewasew Ze-Yared* (መርኆ ግስ ወሰዋስው ዘያሬድ), read from the printed book. The repository also holds labelled forms from other Ge'ez books, a lexicon, Ge'ez–Amharic pairs, prose corpora, and synthetic paradigms generated by rule.

## Sources

| Work | Author | Used for |
|---|---|---|
| *Merho Ges Wesewasew Ze-Yared* | traditional church grammar | gold paradigms |
| *Mets'hafe Sewasew Weges Wemezgebe Qalat Haddis* (1948 E.C.) | Aleqa Kidane Wold Kifle | dictionary, verb triples, grammar tables, Ge'ez–Amharic pairs |
| *Mesehaf Gese Wesewasew* | Liqe Liqawunt Yared Shiferaw | book forms, corpus |
| ርባሐ ስም ወአንቀጽ (1946 E.C.) | አለቃ ደስታ ተክለ ወልድ | book forms |
| ፍሬ ግእዝ; የግእዝ መማሪያ (Year 1); የግዕዝ መማሪያ (ለይኩን ብርሃኑ); ግዕዝ ቋንቋ ፪ | teaching books | book forms |
| A 25-page Ge'ez verb list (no title or author printed) | | headwords with class marks and Amharic glosses |
| ግዕዝ አማርኛ መዝገበ ቃላት | | modern glossary, phrasebook |

Kidane Wold headwords are taken from the typed transcription in [geezorg/data](https://github.com/geezorg/data) (CC BY-SA 4.0). Every row names its book and page.

## Layout

```
data/paradigms/   gold train/val/test files; synthetic training forms
data/unified/     every labelled form of every book in one row schema, with splits; a corrected copy (see below)
data/clitics/     forms with proclitics (ወ, ዘ, ለ, በ, እም) and enclitics (ሰ, ኒ, ሂ, ኑ), made by rule from unified rows
data/books/       forms of ፍሬ ግእዝ, የግዕዝ መማሪያ, Mesehaf Gese Wesewasew and the verb list, one per line
data/synthetic/   synthetic forms whose roots are in val or test (not for training)
data/lexicon/     Kidane Wold dictionary and derived files, modern glossary, book forms
data/parallel/    Ge'ez–Amharic pairs (trusted and uncertain)
data/corpora/     prose and phrasebook
docs/schema.md    field reference
scripts/          check_dataset.py, check_unified.py, build_clitic_forms.py
```

## Row format

Unified rows (`data/unified/geez_morphology_rows.jsonl`), one JSON object per line:

```json
{"id": "u000001", "form": "ሃልሀ", "root": "ሀ-ለ-ሀ", "word_class": "verb", "stem": "basic",
 "tense": "past", "person": "3", "gender": "m", "number": "s", "object": null, "possessor": null,
 "negated": false, "source": "gold", "book": "Mesehaf Gese Wesewasew (Merho Ges)", "page": 19,
 "source_ref": "f0334fe40559:0", "evidence": "gold paradigm", "also_in": [], "status": "",
 "status_reason": "", "split": "train"}
```

- `root`: 2–5 first-order letters joined by `-`; `null` for words without a root.
- `word_class`: `verb`, `noun`, `adjective`, `nominal`, `infinitive`, `gerund`, `verbal_noun`, `pronoun`, `demonstrative`, `preposition`, `particle`, `numeral` (with its root), `adverb`, `proper_noun` (a name; no root).
- `stem`: `basic`, `passive`, `causative`, `reciprocal`, `aste`, `aste_reciprocal`.
- `tense`: `past`, `present`, `subjunctive`, `imperative`.
- `status`: `""` means the row loads; otherwise `CHECK`, `CONFLICT`, `NO_ROOT`, `FLAGGED` or `EXCLUDED`, with `status_reason`.

Gold files (`data/paradigms/merho_ges_gold_*.jsonl`) hold one record per entry with `record_id`, `root`, `page_number`, `paradigm_class` and a `table_data` list of rows (`person`, `gender`, `number`, `tense`, `geez_form`, `amharic_equivalent`, ...). A `geez_form` may hold several spellings separated by ` / `. Synthetic lines are `{"features": {...}, "surface_form": "..."}` (`"analysis"` in the `_analyze` files). Full field reference: [docs/schema.md](docs/schema.md).

## Splits

A root appears in only one of train, val and test. Book rows follow the split of the gold form or root they match, otherwise a fixed hash rule.

Gold records: train 1,113, val 136, test 222.

Unified rows (45,666 in total) that load:

| | train | val | test | not loaded |
|---|---:|---:|---:|---:|
| gold (Merho Ges) | 8,133 | 1,155 | 1,559 | 1,113 |
| other books | 10,881 | 663 | 883 | 21,279 |
| total | 19,014 | 1,818 | 2,442 | 22,392 |

The gold loader expands spellings to 8,094 / 1,153 / 1,554 pairs; these differ from the unified-row counts above.

Synthetic training forms: 120,685 lines. Synthetic forms for val/test roots: 17,569 lines.

## Loading

```python
import json

rows = [json.loads(l) for l in open("data/unified/geez_morphology_rows.jsonl", encoding="utf-8")]
train = [r for r in rows if r["status"] == "" and r["split"] == "train"]
```

Use only rows with an empty `status`. Do not train on `data/synthetic/`.

`data/unified/geez_morphology_rows_reviewed.jsonl` is the same file with corrections to held rows applied: 0 more
rows load (23,274 in total: train 19,014, val 1,818, test 2,442). Rows load there only when the dataset itself
supports the correction; see [data/unified/README.md](data/unified/README.md#corrected-rows-file).

`data/clitics/clitic_forms.jsonl` holds 69,714 forms with Ge'ez proclitics and enclitics (ወገብረ, ለሕዝብ, ገብረሰ),
made by rule from the settled corrected rows; each keeps the root, labels and split of its source row
([data/clitics/README.md](data/clitics/README.md)).

Check the data:

```bash
python scripts/check_dataset.py
python scripts/check_unified.py .
python scripts/check_unified.py . data/unified/geez_morphology_rows_reviewed.jsonl
cd data && sha256sum -c SHA256SUMS
```
